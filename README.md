## ✨ Sobre o projeto

Este projeto representa o primeiro passo na criação de uma página web publicada.

A interface apresenta uma lâmpada que pode ser ligada e desligada por meio de um botão, demonstrando como o JavaScript pode alterar o conteúdo e o estilo da página em tempo real.

## 🎯 Funcionalidades

- Alternância entre lâmpada apagada 🌑 e acesa 💡;
- Atualização dinâmica das mensagens;
- Botão que alterna entre **Ligar** e **Desligar**;
- Mudança entre tema escuro e claro;
- Interação com elementos da página usando JavaScript.

## 🧰 Tecnologias utilizadas

| Tecnologia | Uso no projeto |
| --- | --- |
| **HTML5** | Estrutura e conteúdo da página |
| **CSS3** | Estilos, cores, espaçamento e transições |
| **JavaScript** | Interatividade e manipulação do DOM |
